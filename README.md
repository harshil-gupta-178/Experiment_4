# Experiment 4: Webpage Optimization for SEO and Accessibility (Cybersecurity Theme)

## Objective
Optimize a given webpage for SEO and accessibility by implementing semantic HTML, proper heading structure, and cybersecurity-focused meta tags.

## Implemented Features
1. **Cybersecurity-Targeted SEO**:
   - High-value keyword optimization: *zero trust, penetration testing, threat intelligence, MDR, SOC 2*.
   - Structured `<title>`, `<meta name="description">`, Open Graph metadata, and Twitter Card tags.
   - Search engine directives (`robots`, canonical link).
2. **Semantic HTML5 Architecture**:
   - Proper landmark structure: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, and `<footer>`.
   - Single distinct `<h1>` followed by logical `<h2>` and `<h3>` tags without skipping levels.
3. **Accessibility (a11y) & WCAG 2.1 Compliance**:
   - `<html lang="en">` declaration.
   - Screen-reader accessible "Skip to main content" link.
   - Semantic ARIA attributes (`aria-label`, `aria-labelledby`, `role="banner|main|contentinfo"`).
   - Descriptive `alt` text on images for screen readers.
